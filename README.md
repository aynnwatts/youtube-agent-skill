# YouTube agent skills

Project-local install of [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill)
(commit a2feb21, MIT — see `LICENSE.youtube-agent-skill`).

The eleven `/yt-*` skills live in `.claude/skills/`. Fill in `templates/voice.md` and copy it to
`~/.claude/youtube/voice.md` so every skill writes in your voice.
