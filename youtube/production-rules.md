# Cirrus Land production rules (master prompt project, v21)

The rules for the restoration-documentary Image + Veo prompt system. Apply them to every Image and Veo
prompt until a project is finished.

## Every prompt

- Insert the complete **Universal Human Scale, Architectural Scale & Site Integrity Block** into EVERY
  Image and EVERY Veo prompt, unabridged. Insert every required block yourself; never ask the user to.
  Do a persistence check before delivering any prompt. Name and scope any exception inside the prompt.
- Universal Block clauses (written in full every time): human scale ~1.70 m; the entrance door is
  always visibly taller than workers; constant scale through camera moves; Image->Veo scale continuity;
  non-contact access (spider platform / free-standing tower on stable ground, nothing leans on or loads
  the shell); reference element integrity; access adapts to the building; water-feature lock;
  safety-conflict correction (placement only); final scale hierarchy; preceding-state continuity;
  material replacement matches the target exactly; deep target-match check; full worker uniform;
  non-destructive item movement; Veo 3.1 Fast optimization; persistence check.
- **Natural Organic Form & Vegetation Realism Lock** in every Image and Veo: trees, plants, rocks,
  terrain and water keep natural, irregular, species-appropriate forms and their exact reference
  identity and position. No geometric, symmetrical or plastic vegetation. Wind sways foliage without
  changing its structure.
- Write out the project's full worker uniform wherever workers appear (in the block and in the scene
  text). Never "full crew spec" shorthand.

## Veo

- Optimize for **Veo 3.1 Fast (Google Flow)**: the Image is the authoritative start state, Veo only
  animates it; one coherent action / camera move; clear sequential motion; 16:9; keep the PRECEDING
  IMAGE CONTINUITY LOCK.
- Veo 3.1 Lite is a lower-priority fallback, used only when the user selects it. Then simplify to one
  action and one camera move, keeping every reference and continuity lock.
- **Audio:** NO voice, narration, dialogue or music in any Veo, documentary clips included. The user
  records voice-over separately. Natural, material-accurate ASMR only.
- Every Veo's Start Image = the previous Veo's End Image, across batch and room seams too. Add bridge
  Veos where needed; bridge user-provided establishing images on both sides; never reuse one image
  number for two different frames.
- Every Veo has its End Image prompt written out. Never skip images.
- Deliver in batches with a chain-check table.
- No fade/dissolve transitions. Use physical camera moves (push-through, slide, staircase ascent).
- Secondary-shot fidelity: detail shots show only what the Start/End Images and references support. No
  unseen sides, hidden areas or invented objects; if continuity can't be guaranteed, stay on the PCA.

## Reference analysis and geometry

- Deep reference analysis before every Image/Veo: unchanged elements, restoration targets, removals,
  new target elements. Flag conflicts instead of silently choosing.
- Do not expand rooms or spaces in any phase. Keep the before-image geometry exactly.
- Remove everything old (furniture, décor, fixtures, finishes) before rebuilding; the replacement
  matches the target reference exactly; replace only what genuinely needs it.
- Non-destructive removal: never cut or breach walls, floors, doors or windows to move items; use
  existing access routes; reposition or disassemble anything too large.
- Extract and lock exact hex palettes from the target reference before finishing work. Re-analyze if
  asked.
- Lighting fixtures, candles and lanterns installed but unlit; restored windows read reflective, not
  glowing; match the reference's lighting character with daylight.

## Uniqueness (the monetization problem is "repetitive content")

- Each room's phase/step order is unique versus all previous restorations.
- Each reveal is unique versus every previous reveal (see the log below).
- Every newly entered room gets its own unique documentary-style introduction.
- Reveals are generated only when requested; a lights-on / fire-lighting activation moment may be
  included when requested.

## Crews

- Each room's crew has its own distinct uniform/equipment palette, unchanged within that room. Avoid
  palettes already used (see the log below).
- Phase-specific worker teams: each specialist phase may get its own realistic trade team and
  practical uniform (not costume changes). Uniforms arrive clean and pick up only the
  dust/mud/paint/water their visible task produces; keep each worker's uniform and soiling continuous
  between Image and Veo.
- Worker exit/re-entry scale lock: workers leave and enter by physically accessible routes, appear
  small at a distance and grow only as they approach; feet on the ground with real shadows; no popping
  in, teleporting or size change while stationary.
